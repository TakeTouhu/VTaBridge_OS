# Collaborative Robots 設計

Version: 1.0

Status: Draft

Priority: ★★★★★

---

# 1. 概要

人と同一空間で作業する協働ロボットの安全設計、導入、制御、運用を定義する。

# 2. 用途

組立、検査、梱包、機械投入、ピッキング、作業支援を対象とする。

# 3. 安全機能

- Power and Force Limiting
- Speed and Separation Monitoring
- Safety Rated Stop
- Hand Guiding
- Emergency Stop

# 4. 導入プロセス

リスク評価、作業設計、安全検証、教育、試運転、承認、継続監視を実施する。

# 5. Integration

画像認識、作業指示、MES、品質管理、Digital Twinと連携する。

# 6. KPI

作業時間、安全停止回数、稼働率、不良率、作業者負荷、投資対効果を管理する。

# 7. 将来構想

作業者の意図を理解して動作を適応するHuman-Aware Cobotを実現する。
