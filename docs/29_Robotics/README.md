# 概要

本ディレクトリでは、VTaBridge OSにおけるロボティクス基盤全体を定義する。

産業ロボット、協働ロボット、AMR、AGV、ドローン、Edge AI、Digital Twin、MES、WMSを統合し、安全で柔軟な自動化を実現する。
