# Robotics Metrics 設計

Version: 1.0

Status: Draft

Priority: ★★★★☆

---

# 1. 概要

ロボティクス基盤の価値、性能、安全、品質、コスト、運用品質を評価する共通指標を定義する。

# 2. 生産性指標

自動化率、処理件数、サイクルタイム、タスク完了率、空走率を管理する。

# 3. 信頼性指標

稼働率、MTBF、MTTR、停止時間、再起動回数、通信断時間を管理する。

# 4. 品質指標

作業精度、不良率、再作業率、認識精度、位置決め精度を管理する。

# 5. 安全・セキュリティ指標

事故、ニアミス、安全停止、未承認変更、脆弱性、更新適用率を管理する。

# 6. 経営指標

コスト削減額、人時削減、投資回収期間、エネルギー使用量、設備総合効率への寄与を管理する。

# 7. 可視化

現場、運用、管理者、経営層向けに役割別ダッシュボードと定期レポートを提供する。
