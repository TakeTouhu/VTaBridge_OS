# AGV 設計

Version: 1.0

Status: Draft

Priority: ★★★★☆

---

# 1. 概要

無人搬送車（AGV）の走行経路、搬送指示、交通制御、充電、保守を標準化する。

# 2. 対象方式

磁気誘導、マーカー誘導、レーザー誘導、QR誘導、ハイブリッド方式を対象とする。

# 3. 主な機能

搬送指示、ルート選択、交差点制御、設備連携、自動充電、異常停止を管理する。

# 4. Integration

WMS、MES、コンベヤー、PLC、自動倉庫、フリート管理と連携する。

# 5. 安全

速度制限、障害物検知、非常停止、警告表示、立入区域管理を適用する。

# 6. KPI

搬送完了率、平均搬送時間、待機時間、停止時間、充電効率、事故件数を管理する。

# 7. 将来構想

AGVとAMRを統合配車する共通フリート基盤へ移行する。
