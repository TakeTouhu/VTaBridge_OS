# 概要

本ディレクトリでは、VTaBridge OSにおけるEdge Computing基盤全体を定義する。

Azure IoT Edge、Azure Arc、Kubernetes、Container、Edge AIを中核に、現場処理・低遅延制御・オフライン継続・クラウド連携を統合する。
