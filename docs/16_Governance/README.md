# 概要

本ディレクトリでは、VTaBridge OS全体のガバナンス・ポリシー・リスク管理・コンプライアンス・AIガバナンス・アーキテクチャ統制を定義する。

Enterprise Architecture・COBIT・TOGAF・NIST CSF・ISO 27001・Microsoft Cloud Adoption Framework・Responsible AIを採用し、組織全体で一貫したITガバナンスを実現する。
