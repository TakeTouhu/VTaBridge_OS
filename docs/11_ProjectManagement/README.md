# 概要

本ディレクトリでは、VTaBridge OSのプロジェクト運営・ガバナンス・要件管理・スコープ管理・スケジュール管理・リスク管理・品質管理・コミュニケーション・成果物管理について定義する。

PMBOK・Scrum・Agile・DevOpsの考え方を取り入れ、エンタープライズレベルのプロジェクト運営を実現する。
