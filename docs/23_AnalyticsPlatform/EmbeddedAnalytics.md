# Embedded Analytics 設計

Version: 1.0

Status: Draft

Priority: ★★★★☆

---

# 1. 概要

Embedded Analyticsは、業務アプリケーションやポータル内に分析機能を組み込み、利用者が業務の流れを中断せずに判断できるようにする基盤である。

Power BI Embedded、Microsoft Fabric、Power Apps、Dynamics 365を統合して提供する。

---

# 2. 目的

- 業務内分析
- 利用体験向上
- 意思決定迅速化
- 分析定着
- 再利用促進
- 外部顧客向け分析提供
