Version: 1.0

Status: Draft

# 1. 概要

Prescriptive Analyticsは、予測結果と業務制約を基に最適な行動案を提示する分析基盤である。

Microsoft Fabric、Azure Machine Learning、AI Platform、Power Platformを連携し、意思決定から実行までを支援する。

---

# 2. 目的

- 最適施策提示
- 意思決定迅速化
- コスト最適化
- リスク低減
- 資源配分最適化
- 自動化促進
