# 概要

本ディレクトリでは、VTaBridge OSにおけるIoT基盤全体を定義する。

Azure IoT、Microsoft Fabric、Digital Twin、Edge Computing、AI Platformを統合し、デバイス接続・データ収集・監視・分析・制御を実現する。
