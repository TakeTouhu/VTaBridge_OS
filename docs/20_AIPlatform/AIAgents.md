# 1. 概要

AI Agentsは、VTaBridge OSにおける自律型AIエージェントの設計・実行・管理・連携を定義する。

Microsoft Copilot Studio・Azure AI Foundry・Semantic Kernel・Model Context Protocol（MCP）・OpenAI Agentパターンを採用し、業務を自律的に実行するAIエージェント基盤を構築する。
