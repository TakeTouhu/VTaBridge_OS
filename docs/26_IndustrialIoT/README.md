# 概要

本ディレクトリでは、VTaBridge OSにおけるIndustrial IoT基盤全体を定義する。

OT・IT・Edge・Cloud・AIを統合し、製造設備、制御システム、センサー、データ、業務システムを安全かつリアルタイムに連携する。
