# Industrial Metrics

Version: 1.0

Status: Draft

Priority: ★★★★★

---

# 1. 概要

Industrial Metricsは、Industrial IoTの価値・品質・信頼性・安全性を継続的に評価するための指標体系を定義する。

# 2. ビジネス指標

- OEE
- 生産性向上率
- 不良率
- 計画外停止削減率
- 保全コスト削減率
- エネルギー原単位

# 3. 技術指標

- 接続設備率
- プラットフォーム稼働率
- データ収集成功率
- データ遅延
- 欠損率
- Edge処理成功率

# 4. セキュリティ指標

- 未管理資産数
- 重大脆弱性数
- 不正接続検知数
- インシデント件数
- 復旧時間
- 標準準拠率

# 5. AI指標

- 異常検知精度
- 誤検知率
- 故障予測精度
- モデルドリフト
- AI提案採用率

# 6. レビュー

- 日次運用レビュー
- 月次KPIレビュー
- 四半期価値評価
- 年次ロードマップ更新
