# Smart Factory Security 設計

Version: 1.0

Status: Draft

Priority: ★★★★★

---

# 1. 概要

Smart Factory Securityは、OT・IT・Edge・Cloud・Robot・IoTを対象とした多層防御とZero Trustを定義する。

# 2. 基本方針

- Safety First
- Zero Trust for OT
- Defense in Depth
- Least Privilege
- Secure by Design
- Assume Breach

# 3. 管理策

- 資産台帳
- ネットワーク分離
- 強固な認証
- 特権アクセス管理
- 脆弱性・パッチ管理
- バックアップ・復旧
- 監視・インシデント対応

# 4. OT固有対策

- 許可リスト通信
- 保守端末統制
- リモート接続承認
- 変更影響評価
- 安全系との分離

# 5. KPI

- 管理対象資産率
- 脆弱性是正率
- 不正接続件数
- MTTD / MTTR
- 復旧訓練達成率

# 6. 将来像

工場全体のリスクを継続評価し、生産影響を考慮して防御・検知・復旧を最適化する。
