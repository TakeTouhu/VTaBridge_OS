# Smart Factory Metrics 設計

Version: 1.0

Status: Draft

Priority: ★★★★★

---

# 1. 概要

Smart Factory Metricsは、経営・工場・ライン・設備・品質・保全・エネルギーの成果を一貫して評価するKPI体系を定義する。

# 2. 経営KPI

- 投資対効果
- 製造原価
- 納期遵守率
- 生産能力
- 在庫回転率

# 3. 現場KPI

- OEE
- 稼働率
- 性能効率
- 良品率
- スループット
- サイクルタイム

# 4. 品質・保全KPI

- FPY
- 不良率
- MTBF
- MTTR
- 計画外停止時間
- 予防保全比率

# 5. デジタルKPI

- 接続設備率
- データ品質
- 自動化率
- AI利用率
- モデル精度
- 標準再利用率

# 6. 管理方針

KPIごとに定義、計算式、所有者、データソース、更新頻度、目標値を管理する。
