# 概要

本ディレクトリでは、VTaBridge OSにおけるSmart Factory全体を定義する。

IoT、Edge、Industrial IoT、MES、SCADA、Digital Twin、Robotics、AI、Data Platformを統合し、可視化・予測・最適化・自律化された次世代製造拠点を実現する。
