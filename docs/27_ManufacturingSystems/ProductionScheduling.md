# Production Scheduling 設計

Version: 1.0

Status: Draft

Priority: ★★★★★

---

# 1. 概要

Production Schedulingは、設備・人員・治工具・材料・納期の制約を考慮し、実行可能な詳細生産スケジュールを作成する。

# 2. 管理対象

- 製造オーダー
- 工程
- 設備能力
- 作業者スキル
- 段取り
- 優先順位

# 3. 主な機能

- 有限能力スケジューリング
- ガントチャート
- 制約管理
- 段取り最適化
- 再スケジューリング
- MES連携

# 4. AI活用

- 最適順序生成
- 遅延予測
- ボトルネック検知
- 動的再計画
- シナリオ比較

# 5. KPI

- スケジュール遵守率
- 段取り時間
- 設備負荷率
- 待ち時間
- 納期遅延件数
