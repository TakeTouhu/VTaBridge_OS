# MES 設計

Version: 1.0

Status: Draft

Priority: ★★★★★

---

# 1. 概要

MESは、生産指示・作業実績・品質・設備・人員・材料をリアルタイムに管理する製造実行基盤である。

# 2. 管理対象

- 製造オーダー
- 工程実績
- 作業者
- 設備
- 材料
- 品質記録

# 3. 主な機能

- 作業指示
- 実績収集
- WIP管理
- 工程進捗監視
- 電子作業標準
- 異常管理

# 4. Integration

- ERP
- SCADA
- PLM
- QMS
- WMS
- IoT Platform

# 5. KPI

- OEE
- 生産数量
- サイクルタイム
- 不良率
- 停止時間
- 計画達成率
