# Manufacturing Metrics 設計

Version: 1.0

Status: Draft

Priority: ★★★★★

---

# 1. 概要

Manufacturing Metricsは、製造パフォーマンスを一貫して測定・評価・改善するための指標体系を定義する。

# 2. 生産指標

- OEE
- 生産数量
- 計画達成率
- サイクルタイム
- 稼働率
- 段取り時間

# 3. 品質指標

- 不良率
- 直行率
- 手直し率
- スクラップ率
- 顧客クレーム件数

# 4. 保全指標

- MTBF
- MTTR
- 設備停止時間
- 計画保全率
- 保全コスト

# 5. 物流・原価指標

- 在庫回転率
- 在庫精度
- 納期遵守率
- 製造原価
- エネルギー原単位

# 6. 管理方針

- 定義・計算式の標準化
- データソース明確化
- 更新頻度管理
- 目標値設定
- 拠点横断比較
- 改善アクション連携
