# 概要

本ディレクトリでは、VTaBridge OSにおける製造システム全体を定義する。

ERP、MES、SCADA、PLM、QMS、WMS、IoT、Digital Twin、AIを統合し、計画・実行・品質・保全・物流・分析を一貫管理する。
