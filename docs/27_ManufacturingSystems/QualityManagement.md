# Quality Management 設計

Version: 1.0

Status: Draft

Priority: ★★★★★

---

# 1. 概要

Quality Managementは、受入・工程・出荷品質を統合管理し、不良の予防・検知・是正を実現する。

# 2. 管理対象

- 検査計画
- 検査結果
- 不適合
- 是正処置
- 品質基準
- 測定機器

# 3. 主な機能

- 受入検査
- 工程内検査
- 出荷検査
- SPC
- 不適合管理
- CAPA

# 4. AI活用

- 外観検査
- 不良予測
- 原因分析
- 品質異常検知
- 検査条件最適化

# 5. KPI

- 不良率
- 直行率
- 手直し率
- 顧客クレーム件数
- CAPA完了時間
