# 1. 概要

Enterprise Architecture Strategyは、VTaBridge OSにおけるエンタープライズアーキテクチャ（EA）の基本方針・原則・ガバナンス・ロードマップを定義し、ビジネス戦略とIT戦略を統合するための設計を定義する。

TOGAF Standard・Zachman Framework・Microsoft Cloud Adoption Framework・Azure Well-Architected Framework・Domain-Driven Design（DDD）・Event-Driven Architecture（EDA）を採用し、持続可能で拡張性の高いアーキテクチャを実現する。

---

Enterprise Architecture導入目的
