# Data Governance 設計

Version: 1.0

Status: Draft

---

# 概要

本ディレクトリでは、VTaBridge OSにおけるデータガバナンス全体を定義する。

Microsoft Purview、Microsoft Fabric、Azure、Dataverse、Power BIを中核に、データ所有権・品質・分類・カタログ・ライフサイクル・プライバシー・コンプライアンスを統合管理する。
