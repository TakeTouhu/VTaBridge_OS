# Data Governance Metrics 設計

Version: 1.0

Status: Draft

Priority: ★★★★☆

---

# 1. 概要

Data Governance Metricsは、データガバナンス施策の成熟度、実行状況、品質、リスク、価値を定量的に評価するための指標体系を定義する。

---

# 2. 目的

- ガバナンス状況の可視化
- 経営報告の標準化
- 改善優先順位の明確化
- 責任者評価
- 投資効果測定
- 継続的改善

---

# 3. 指標カテゴリ

- Ownership
- Metadata
- Quality
- Classification
- Privacy
- Compliance
- Risk
- Value

---

# 4. 主要KPI

| 分類 | KPI |
|---|---|
| Ownership | Owner Assignment Rate |
| Metadata | Metadata Completeness |
| Quality | Data Quality Score |
| Classification | Classification Coverage |
| Privacy | Privacy Request SLA |
| Compliance | Control Compliance Rate |
| Risk | High-Risk Data Asset Count |
| Value | Governed Data Utilization |
