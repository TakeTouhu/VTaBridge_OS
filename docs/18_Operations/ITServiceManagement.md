# 1. 概要

IT Service Management（ITSM）は、VTaBridge OSにおけるITサービスの企画・提供・運用・改善を体系的に管理するための設計を定義する。

ITIL 4・ISO/IEC 20000・Microsoft Azure Well-Architected Framework・Microsoft Cloud Adoption Frameworkを採用し、ビジネス価値を継続的に提供するサービスマネジメントを実現する。

---

# 2. 目的

IT Service Management導入目的

- 安定したサービス提供
- 顧客満足度向上
- SLA遵守
- サービス品質向上
- 運用効率向上
- 継続的改善
