# 1. 概要

Cost Managementは、VTaBridge OSにおけるプロジェクト予算・見積・原価・Azure利用料金・ライセンス費用・ROI・TCO・Earned Value Management（EVM）を管理し、コストの最適化と予算遵守を実現するための設計を定義する。

PMBOK第7版・Earned Value Management（EVM）・FinOps Framework・Microsoft Cost Management・Azure Advisorを採用し、継続的なコスト最適化を実現する。
