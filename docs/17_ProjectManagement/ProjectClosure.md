# 1. 概要

Project Closureは、VTaBridge OSにおけるプロジェクトの正式な終結・成果物引継ぎ・契約完了・運用移管・ナレッジ蓄積・最終評価を体系的に実施するための設計を定義する。

PMBOK第7版・PRINCE2・ITIL 4・Microsoft Cloud Adoption Framework・Knowledge Managementを採用し、プロジェクト成果を組織資産として最大限活用する。
