# 概要

本ディレクトリでは、VTaBridge OSにおけるプロジェクト管理・プロジェクトガバナンス・アジャイル開発・品質管理・進捗管理・リスク管理・ステークホルダー管理を定義する。

PMBOK 第7版・Agile Practice Guide・Scrum Guide・Microsoft Cloud Adoption Framework・GitHub Projectsを採用し、プロジェクトライフサイクル全体を統制する。
