# 1. 概要

Project Management Strategyは、VTaBridge OSにおけるプロジェクト管理の基本方針・ライフサイクル・ガバナンス・開発手法・品質・リスク・ステークホルダー管理を定義する。

PMBOK第7版・Agile Practice Guide・Scrum Guide・PRINCE2・Microsoft Cloud Adoption Frameworkを採用し、プロジェクトの成功確率を最大化する。

---

# 2. 目的

Project Management Strategy導入目的

- プロジェクト成功率向上
- 品質保証
- スケジュール遵守
- コスト最適化
- リスク低減
- 継続的改善
