# 1. 概要

Scrum Managementは、VTaBridge OSにおけるScrumチーム運営・Sprint管理・イベント・成果物・役割・メトリクスを定義する。

Scrum Guide 2020・Agile Manifesto・DevSecOps・GitHub Projects・Azure DevOpsを採用し、高品質かつ継続的な価値提供を実現する。
