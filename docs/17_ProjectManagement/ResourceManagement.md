# 1. 概要

Resource Managementは、VTaBridge OSにおける人的リソース・スキル・役割・要員計画・キャパシティ・稼働率・外部ベンダーを効率的に管理するための設計を定義する。

PMBOK第7版・Agile Practice Guide・Scrum Guide・Microsoft Planner・GitHub Projects・Microsoft Teamsを採用し、最適なリソース配置と生産性向上を実現する。
