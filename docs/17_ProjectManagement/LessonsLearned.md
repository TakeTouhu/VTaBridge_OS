# 1. 概要

Lessons Learnedは、VTaBridge OSにおけるプロジェクト・開発・運用・障害対応から得られた知見・成功要因・失敗要因・改善事項を組織資産として蓄積・共有・再利用するための設計を定義する。

PMBOK第7版・Retrospective・KPT・Knowledge Management・Microsoft Loop・SharePoint・GitHub Wikiを採用し、継続的な組織学習とプロジェクト成功率向上を実現する。

---

# 2. 目的

Lessons Learned導入目的

- ナレッジ蓄積

- 失敗の再発防止
