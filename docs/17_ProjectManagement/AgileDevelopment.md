# 1. 概要

Agile Developmentは、VTaBridge OSにおけるアジャイル開発の原則・開発プロセス・チーム運営・継続的デリバリーを定義する。

Agile Manifesto・Scrum Guide・Kanban Guide・Extreme Programming（XP）・DevSecOps・GitHubを採用し、変化に迅速に対応できる高品質なソフトウェア開発を実現する。

---

# 2. 目的

Agile Development導入目的

- ビジネス価値の早期提供
- 変化への迅速な対応
- 品質向上
- チームコラボレーション強化
- 継続的デリバリー
- 継続的改善

# 10. Definition of Ready

条件

- User Story完成
- Acceptance Criteria明確
- 見積完了
- 依存関係確認
- 優先順位決定
- 開発可能状態

Sprintへ投入する前提条件を定義する。

---

# 11. Definition of Done

条件

- 実装完了
- コードレビュー完了
- テスト成功
- セキュリティチェック完了
- ドキュメント更新
- Product Owner承認

品質基準を満たしたもののみ完了とする。
