# 1. 概要

ERPは、VTaBridge OSにおける会計・販売・調達・在庫・生産・資産・プロジェクト業務を統合し、企業資源を一元管理するための設計を定義する。

Dynamics 365 Finance・Supply Chain Management・Project Operations・Microsoft Fabric・Power Platformを採用し、リアルタイム経営管理を実現する。
