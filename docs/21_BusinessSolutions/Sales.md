# 1. 概要

Sales（営業管理）は、VTaBridge OSにおける営業活動全体を統合管理する。

リード獲得から商談・見積・受注・売上・顧客フォローまでを一元管理し、AIによる営業支援を実現する。

Microsoft Dynamics 365 Sales、Salesforce、HubSpotなどとの連携を前提とする。
