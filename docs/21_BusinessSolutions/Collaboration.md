# 1. 概要

Collaboration（コラボレーション）は、VTaBridge OSにおける組織内外のコミュニケーション、情報共有、共同作業を統合管理するプラットフォームである。

Microsoft Teamsを中心に、Microsoft 365、SharePoint、Outlook、Loop、Planner、GitHub、Boxなどと連携し、AIを活用した次世代コラボレーション環境を提供する。
