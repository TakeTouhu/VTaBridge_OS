# 1. 概要

Enterprise Search（エンタープライズ検索）は、VTaBridge OSにおける企業全体の情報資産を横断検索する統合検索基盤である。

Microsoft Search、Microsoft Graph、Azure AI Search、Microsoft Fabric、SharePoint、Box、Confluence、GitHubなどを統合し、AIによるセマンティック検索とRAGを実現する。
