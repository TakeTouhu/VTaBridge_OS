# 概要

本ディレクトリでは、VTaBridge OSにおける業務ソリューション群の全体設計を定義する。

Microsoft Dynamics 365・Microsoft 365・Power Platform・Microsoft Fabric・SharePoint・Teams・Power BI・Box・Salesforce・SAP・ServiceNowを活用し、営業・会計・調達・人事・顧客サービス・コラボレーションを統合する。
