# 1. 概要

Document Management（文書管理）は、VTaBridge OSにおける企業文書の作成・共有・承認・保管・検索・ライフサイクル管理を統合する基盤である。

Microsoft SharePoint、Box、OneDrive、Microsoft 365、Adobe Acrobat、Microsoft Purviewと連携し、Enterprise Content Management（ECM）を実現する。
