# 1. 概要

Digital Workplaceは、VTaBridge OSにおける従業員のデジタルワークスペースを統合管理する基盤である。

Microsoft 365、Microsoft Teams、SharePoint、OneDrive、Microsoft Viva、Power Platform、AI Platformを統合し、場所やデバイスを問わず生産性を最大化する。
