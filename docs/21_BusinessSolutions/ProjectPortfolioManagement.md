# 1. 概要

Project Portfolio Management（PPM）は、VTaBridge OSにおけるプロジェクト・プログラム・ポートフォリオを統合管理し、企業戦略との整合性を確保するための基盤である。

Microsoft Project、Planner、Azure DevOps、GitHub、Jira、Power BIとの連携を前提とする。

---

# 2. 目的

- 戦略とプロジェクトの整合
- 投資対効果の最大化
- リソース最適化
- リスク管理
- プロジェクト可視化
- AIによる意思決定支援
