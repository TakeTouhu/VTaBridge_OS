# 1. 概要

Knowledge Management（ナレッジ管理）は、VTaBridge OS全体の知識資産を統合管理する基盤である。

企業内のドキュメント・FAQ・設計書・ノウハウ・会議録・技術情報を一元管理し、AIとRAGを活用して必要な情報へ即座にアクセスできる環境を提供する。

Microsoft 365、SharePoint、Box、Confluence、Microsoft Fabricとの連携を前提とする。
