# 概要

本ディレクトリでは、VTaBridge OSにおけるDigital Twin基盤全体を定義する。

設備・製品・工程・空間・人・業務を仮想モデルとして統合し、IoT、Edge、AI、MES、GISと連携してリアルタイム監視、予測、シミュレーション、最適化を実現する。
