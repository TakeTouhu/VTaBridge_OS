# Asset Model

Version: 1.0

Status: Draft

---

# 1. 概要

設備、製品、部品、建物、ラインなどの物理資産をDigital Twinとして表現する資産モデルを定義する。

# 2. 管理項目

- Asset ID
- Asset Type
- Location
- Manufacturer
- Specification
- Operational State
- Maintenance History

# 3. 関係

- Parent / Child
- Installed At
- Connected To
- Produced By
- Maintained By

# 4. ライフサイクル

設計、調達、設置、稼働、保全、更新、廃棄までを一貫管理する。

# 5. 完成像

資産台帳とTwinモデルを統合し、設備状態と履歴をリアルタイムに把握する。
